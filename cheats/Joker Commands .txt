Use the joker commands to enable/disable certain codes during gameplay. Use the joker command if you only want to enable/disable one code at a time, or use the master joker command to enable/disable multiple codes all at the same time.

GS2v3+ (PAL) & Xploder

Controller 1 (Joker Command)
D1FABA02 0000dddd

Controller 1 (Master Joker Command)
Ennndddd 01FABA02

nnn = # of codes under the command to be jokered
dddd = joker command
