
---- Mod - No Locked Vehicles, No Alarms on Vehicles ----


use search function (ctrl + f), find and replace all alarms and locked doors;-
set doors_locked % and alarms to 0
rebuild iso

e.g.
create_car_generator $2776 = init_car_generator #RHINO color -1 -1 force_spawn 1 alarm 0 door_lock 0 min_delay 0 max_delay 10000 at 2435.302 -1671.848 12.8007 angle 90.0

alarm 100
alarm 90 
alarm 80 
....etc
always change the 2 digit values first when mass replacing to avoid a 00 or incorrect numeric replacement scenraio.
